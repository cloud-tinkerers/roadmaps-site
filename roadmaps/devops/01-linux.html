Linux & The Command Line

Every DevOps journey starts here. Linux is the operating system that runs the internet. Most servers, containers, and cloud instances run Linux. If you can't navigate a terminal, you can't do DevOps. This stage teaches you the command line from scratch — no prior experience needed.

1

Understand What Linux Is

Linux is a free, open-source operating system. It powers most of the internet's servers and is the backbone of cloud computing. Learn why it matters and how it differs from Windows/macOS.

2

Set Up Your Environment

Install a Linux distribution (Ubuntu is a great start) on a virtual machine, WSL2, or a cloud instance. Get comfortable with the terminal interface.

3

Navigate the Filesystem

Learn essential commands: ls, cd, pwd, mkdir, cp, mv, rm. Understand the Linux directory hierarchy — /home, /etc, /var, /tmp.

4

Master File Permissions

Understand chmod, chown, and the read/write/execute permission model. Learn why permissions matter for security and how to troubleshoot "permission denied" errors.

5

Manage Processes & Services

Learn to monitor running processes with ps, top, and htop. Start and stop services with systemctl. Understand background processes and job control.

6

Learn SSH & Remote Access

Connect to remote servers securely with SSH. Generate SSH keys, configure key-based authentication, and manage remote sessions — a daily DevOps task.

7

Build Something Real

Set up a basic Linux server: install packages, configure a firewall with ufw, set up a web server (Nginx), and deploy a simple static site. This is your first real infrastructure project.

Tips for This Stage

🖥️ Use It Daily

The fastest way to learn Linux is to use it as your daily driver. Even 20 minutes a day in the terminal builds muscle memory fast.

📝 Break Things on Purpose

Spin up a throwaway VM and experiment. Delete files, change permissions, kill processes — learn what happens and how to fix it.

🔍 Read the Man Pages

Every command has a manual. Type man ls or ls --help. Learning to read documentation is a superpower.

🚀 Don't Memorise — Practise

You don't need to memorise every flag. You need to know what's possible and look up the rest. Practice beats flashcards.
